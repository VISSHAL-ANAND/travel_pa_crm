## 🎯 Project Overview

The **Travel-PA CRM Platform** is a full-stack application designed to manage travel agency operations. It enables:

- **Admins** to manage agents, view all leads, and access system-wide feedback analytics
- **Agents** to manage client leads, customize intake questionnaires, generate PDF reports, and receive email notifications
- **Clients** to submit travel requests via a guided questionnaire and provide feedback
- **AI-powered** onboarding summaries generated by Google Gemini for every new lead
- **Automated** email delivery of PDF reports to assigned agents

This is a **multi-user** system with role-based access (Admin, Agent, Client).

---

## ✨ Features

### Admin Dashboard
- Create, view, and delete travel agents
- View all client leads across every agent
- Access system-wide feedback and ratings
- Unique shareable intake links per agent

### Agent Portal
- View and manage assigned client leads
- Update lead status (new, contacted, booked, etc.)
- Customize client intake form questions and configuration
- View feedback and ratings specific to their clients
- Shareable client intake link auto-assigned to the agent

### Client Intake Questionnaire
- Guided multi-step travel questionnaire
- Captures trip dreams, destination, budget, travel dates, special occasions, and more
- Agent-specific customizations applied dynamically
- AI-generated travel strategy summary on submission

### Feedback System
- Multi-dimensional ratings (overall, service, value, recommendation)
- Continue-booking preference tracking (yes / maybe / no)
- Feedback linked to both clients and agents
- Admin can view all feedback; agents see only their own

### Additional Features
- 🤖 **AI Integration** — Google Gemini generates a professional travel strategy summary for each new lead
- 📧 **Email Notifications** — Automated PDF report delivery to the assigned agent via Nodemailer
- 🔐 **Secure Authentication** — Bcrypt password hashing for agent credentials
- 📄 **PDF Generation** — Branded A4 onboarding reports with logo, client profile, and AI assessment
- 🛠️ **Custom Form Config** — Agents can customize their intake questionnaire sections and options
- 🌐 **CORS Enabled** — API ready for frontend integration

## 🚀 Installation & Setup

### Step 1: Clone the Repository

```bash
git clone <your-repo-url>
cd TRAVEL-PA_CRM
```

### Step 2: Install Dependencies

```bash
npm install
```

This will install all required packages from `package.json`:
- Express.js, Supabase JS client, Google Gemini API
- Nodemailer, Bcrypt, PDFKit, CORS, Dotenv

### Step 3: Set Up Environment Variables

Create a `.env` file in the root directory:

```env
# Google Gemini API
GEMINI_API_KEY=your_gemini_api_key_here

# Supabase Configuration
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key_here

# Admin Setup
DEFAULT_ADMIN_NAME=Admin
DEFAULT_ADMIN_EMAIL=your_admin_email@example.com
ADMIN_PASSWORD=secure_password_here

# Email Configuration (Gmail)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your_gmail@gmail.com
SMTP_PASS=your_gmail_app_password

# Fallback Email (used when a lead has no assigned agent)
DEFAULT_AGENT_FALLBACK_EMAIL=your_gmail@gmail.com
```

## ⚙️ Environment Configuration

### 1. Google Gemini API Setup

1. Go to [Google AI Studio](https://ai.google.dev/)
2. Click "Get API Key"
3. Create a new API key
4. Copy and paste into `GEMINI_API_KEY` in `.env`

### 2. Supabase Setup

1. Sign up at [Supabase](https://supabase.com)
2. Create a new project
3. Go to **Settings → API**
4. Copy `Project URL` → `SUPABASE_URL`
5. Copy `Service Role Key` → `SUPABASE_SERVICE_ROLE_KEY`
6. Run the database schema (see [Database Setup](#database-setup) below)

### 3. Gmail App Password Setup

1. Enable 2-Factor Authentication on your Gmail account
2. Go to [Gmail App Passwords](https://myaccount.google.com/apppasswords)
3. Generate an app password for "Mail"
4. Use this 16-character password as `SMTP_PASS`

## 🗄️ Database Setup

### Option 1: Using Supabase Console (Recommended)

1. Log in to your Supabase project
2. Go to **SQL Editor**
3. Click **New Query**
4. Copy the entire content from `db/schema.sql`
5. Paste it into the SQL editor and click **RUN**

### Option 2: Using psql CLI

```bash
psql -h your-supabase-host -U postgres -d postgres -f db/schema.sql
```

### Database Schema Overview

The schema is idempotent and safe to run multiple times — it never deletes existing data.

#### `admins`
| Column       | Type | Notes                |
|--------------|------|----------------------|
| `id`         | UUID | Primary key (auto)   |
| `admin_name` | TEXT | Required             |
| `email`      | TEXT | Unique, required     |

#### `agents`
| Column       | Type | Notes                          |
|--------------|------|--------------------------------|
| `id`         | UUID | Primary key (auto)             |
| `admin_id`   | UUID | FK → `admins.id` (cascade)     |
| `agent_name` | TEXT | Required                       |
| `email`      | TEXT | Unique, required               |
| `password`   | TEXT | Bcrypt-hashed                  |

#### `clients`
| Column                 | Type        | Notes                          |
|------------------------|-------------|--------------------------------|
| `id`                   | UUID        | Primary key (auto)             |
| `customer_id`          | UUID        | Secondary ID (auto)            |
| `agent_id`             | UUID        | FK → `agents.id` (cascade)     |
| `first_name`           | TEXT        | —                              |
| `last_name`            | TEXT        | —                              |
| `email`                | TEXT        | —                              |
| `phone`                | TEXT        | —                              |
| `region`               | TEXT        | —                              |
| `destination_specific` | TEXT        | —                              |
| `destination`          | TEXT        | —                              |
| `budget`               | TEXT        | —                              |
| `travel_date`          | TEXT        | Start date                     |
| `travel_date_end`      | TEXT        | End date                       |
| `notes`                | TEXT        | —                              |
| `status`               | TEXT        | Default: `'new'`               |
| `custom_answers`       | JSONB       | Default: `'{}'`                |
| `created_at`           | TIMESTAMPTZ | Default: UTC now               |

#### `feedback`
| Column             | Type        | Notes                              |
|--------------------|-------------|------------------------------------|
| `id`               | UUID        | Primary key (auto)                 |
| `client_id`        | UUID        | FK → `clients.id` (set null)       |
| `agent_id`         | UUID        | FK → `agents.id` (set null)        |
| `client_name`      | TEXT        | Required                           |
| `client_email`     | TEXT        | Required                           |
| `message`          | TEXT        | Required                           |
| `overall_rating`   | INTEGER     | 1–5                                |
| `service_rating`   | INTEGER     | 1–5                                |
| `value_rating`     | INTEGER     | 1–5                                |
| `recommend_rating` | INTEGER     | 1–5                                |
| `continue_booking` | TEXT        | `'yes'` / `'maybe'` / `'no'`      |
| `agent_email`      | TEXT        | —                                  |
| `created_at`       | TIMESTAMPTZ | Default: UTC now                   |

#### `agent_form_config`
| Column             | Type        | Notes                          |
|--------------------|-------------|--------------------------------|
| `agent_id`         | UUID        | PK, FK → `agents.id` (cascade)|
| `custom_questions` | JSONB       | Default: `'[]'`                |
| `main_config`      | JSONB       | Default: `null`                |
| `updated_at`       | TIMESTAMPTZ | Default: UTC now               |

**Indexes:** `agents.admin_id`, `clients.agent_id`, `feedback.client_id`, `feedback.agent_id`, `feedback.created_at` (DESC)

## 🔌 API Endpoints

All API routes are prefixed with `/api`.

### Authentication

| Method | Endpoint            | Description                              |
|--------|---------------------|------------------------------------------|
| POST   | `/api/auth/login`   | Unified login (role: `admin` or `agent`) |

**Request body:**
```json
{
  "role": "admin | agent",
  "email": "agent@example.com",
  "password": "password123"
}
```

---

### Admin Routes (require admin auth)

| Method | Endpoint                  | Description                        |
|--------|---------------------------|------------------------------------|
| GET    | `/api/admin/agents`       | List all agents with client counts |
| POST   | `/api/admin/agents`       | Create a new agent                 |
| DELETE | `/api/admin/agents/:id`   | Delete an agent                    |
| GET    | `/api/admin/leads`        | List all client leads              |
| GET    | `/api/admin/feedback`     | List all feedback entries          |

---

### Agent Routes (require agent auth)

| Method | Endpoint                          | Description                              |
|--------|-----------------------------------|------------------------------------------|
| GET    | `/api/agent/leads`                | List the agent's assigned leads          |
| PATCH  | `/api/agent/leads/:id/status`     | Update a lead's status                   |
| GET    | `/api/agent/link`                 | Get the agent's shareable intake link    |
| GET    | `/api/agent/form-config`          | Get the agent's custom form config       |
| PUT    | `/api/agent/form-config`          | Save/update the agent's form config      |
| GET    | `/api/agent/feedback`             | Get feedback for this agent              |

---

### Public Routes (no auth required)

| Method | Endpoint                              | Description                             |
|--------|---------------------------------------|-----------------------------------------|
| POST   | `/api/new-lead`                       | Submit a new client intake questionnaire|
| POST   | `/api/feedback`                       | Submit client feedback                  |
| GET    | `/api/public/form-config/:agentId`    | Get an agent's form config (public)     |

---

### Static / Utility Routes

| Method | Endpoint               | Description                     |
|--------|------------------------|---------------------------------|
| GET    | `/`                    | Redirects to Client Portal      |
| GET    | `/Report_*.pdf`        | Serve generated PDF reports     |
| GET    | `/admin/*`             | Serve admin static files        |
| GET    | `/client/*`            | Serve client static files       |

## 🌐 Deployment Guide

### Option 1: Deploy to Heroku

1. Install Heroku CLI: https://devcenter.heroku.com/articles/heroku-cli
2. Create Heroku account and app:
   ```bash
   heroku login
   heroku create your-app-name
   ```

3. Set environment variables:
   ```bash
   heroku config:set GEMINI_API_KEY="your_key"
   heroku config:set SUPABASE_URL="your_url"
   heroku config:set SUPABASE_SERVICE_ROLE_KEY="your_key"
   heroku config:set DEFAULT_ADMIN_EMAIL="your_email"
   heroku config:set ADMIN_PASSWORD="your_password"
   heroku config:set SMTP_USER="your_smtp_user"
   heroku config:set SMTP_PASS="your_smtp_pass"
   ```

4. Deploy:
   ```bash
   git push heroku main
   ```

### Option 2: Deploy to AWS / DigitalOcean / VPS

1. Set up a Linux server (Ubuntu 22.04+)
2. Install Node.js v20+
3. Clone repository and install dependencies
4. Use PM2 for process management:
   ```bash
   npm install -g pm2
   pm2 start server.js --name "travel-crm"
   pm2 startup
   pm2 save
   ```
5. Set up Nginx as a reverse proxy
6. Enable SSL with Let's Encrypt

### Option 3: Deploy with Docker

Create a `Dockerfile`:
```dockerfile
FROM node:20-alpine

WORKDIR /app

COPY package*.json ./
RUN npm ci --only=production

COPY . .

ENV PORT=5005
EXPOSE 5005

CMD ["npm", "start"]
```

Build and run:
```bash
docker build -t travel-pa-crm .
docker run -p 5005:5005 --env-file .env travel-pa-crm
```

## 🔧 Troubleshooting

### "GEMINI_API_KEY is missing"

1. Ensure `.env` file exists in the project root
2. Add `GEMINI_API_KEY=your_key` to `.env`
3. Restart the server: `npm start`

### "Supabase not configured"

1. Get `SUPABASE_URL` from **Supabase Dashboard → Settings → API**
2. Get `SUPABASE_SERVICE_ROLE_KEY` from the same page
3. Add both to `.env` and restart

### "DEFAULT_ADMIN_EMAIL is missing" / Server exits on startup

1. Add `DEFAULT_ADMIN_EMAIL=your_email@example.com` to `.env`
2. Ensure the email is in a valid format
3. Run `npm start` again

### Email not sending

1. Verify Gmail 2FA is enabled
2. Generate a new app password: https://myaccount.google.com/apppasswords
3. Update `SMTP_USER` and `SMTP_PASS` in `.env`
4. Verify `SMTP_HOST=smtp.gmail.com` and `SMTP_PORT=587`

### "Cannot connect to database"

1. Verify your Supabase project is active (not paused)
2. Check `SUPABASE_URL` format: `https://your-project.supabase.co`
3. Verify you're using the **Service Role Key** (not the public anon key)
4. Run `db/schema.sql` in the Supabase SQL editor

### Port already in use

```bash
# Windows
netstat -ano | findstr :5005
taskkill /PID <process_id> /F

# Mac/Linux
lsof -i :5005
kill -9 <process_id>
```

Or set a different port in `.env`:
```env
PORT=3000
```

##  Security Best Practices

1. **Never commit `.env` to Git**
   - `.env` is already in `.gitignore`

2. **Use strong passwords**
   - Admin password should be 12+ characters
   - Include uppercase, lowercase, numbers, and symbols

3. **Rotate API keys regularly**
   - Update Gemini API key periodically
   - Regenerate Supabase keys if compromised

4. **Enable HTTPS in production**
   - Use Let's Encrypt for free SSL certificates
   - Configure your reverse proxy (Nginx) for HTTPS

5. **Keep dependencies updated**
   ```bash
   npm audit
   npm update
   ```

6. **Never expose credentials in README or source code**
   - Use environment variables for all secrets
